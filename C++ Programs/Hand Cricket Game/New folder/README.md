\# Cricket Game - Ultimate Edition



A feature-rich cricket game with GUI interface built using Qt framework.



\## Features

\- 🏏 Interactive GUI with cricket theme

\- 🔐 User authentication system

\- 🎮 Human vs Computer gameplay

\- 📊 Live scoreboard and progress tracking

\- 💬 Real-time commentary

\- 🎯 Random toss system

\- 📈 Statistics tracking



\## Requirements

\- Qt 5 or Qt 6 framework

\- C++11 compatible compiler



\## Installation



\### Linux/Mac

```bash

qmake cricket\_game.pro

make

./CricketGame
